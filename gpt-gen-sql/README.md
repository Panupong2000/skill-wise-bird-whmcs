# WHMCS AI Database Agent

This project allows an AI agent to query a WHMCS database using natural language.

Example questions:
1.ใครมีหลายโดเมนแต่ยังไม่ใช้ Multi-Server
-ใครมีหลายโดเมน,ใครมีโฮสต์เดียว,ใครมี vps เดียว
2.ใครมี Traffic โตขึ้นเกิน 30% ใน 3 เดือนล่าสุด
3.ใครกำลังใช้ Shared Hosting แต่มีพฤติกรรมเหมาะกับ VPS
4.ใครยังไม่มี Email Hosting
5.ลูกค้าเฉลี่ยจ่ายกี่บาทต่อปี
-ชื่อลูกค้า รายจ่ายต่อปี 5 ปี ย้อนหลัง เรียงจากเยอะไปน้อย 
6.ลูกค้ารายใดที่ใช้จ่ายมาก หรือ น้อย ที่สุด ต่อปี
7.แพ็กเกจใดที่คนสั่งซื้อน้อยสุด (มากสุดไปน้อยสุด)
-สั่งซื้อใหม่
-ต่ออายุ
8.ลูกค้ารายใด สามารถอัพเกรดขาย.... ได้
-ซื้อสินค้าหลายอย่าง
9.รายชื่อลูกค้าที่ไม่ได้ต่ออายุในปี 2025 
10.Top 5 แพ็คเกจยอดนิยม
11.ลูกค้าที่จ่ายล่วงหน้า มากกว่า 2-5 ปี
12.รายได้แยกตามแพ็คเกจ (เช่น Hosting, Domain, Email , Website)
ลูกค้าใหม่ และ ลูกค้าต่ออายุ
13.ยอดขายทั้งหมดปีที่แล้ว เท่าไหร่ ปีนี้เท่าไหร่ คิดเป็นกี่เปอร์เซ็นต์
14.สัปดาห์นี้ควรโทรหาลูกค้าคนไหนก่อน
-ลูกค้าที่กำลังจะหมดอายุยอดขายมากสุด 1000 คน
15.ลูกค้ารายใดสร้างรายได้มากแต่มีความเสี่ยงยกเลิก
-ลูกค้าซ์้อใหม่อย่างเดียว แต่ไม่ต่ออายุ
16.ลูกค้ารายใดมีศักยภาพจ่ายเพิ่ม (ต้องไปเชื่อมกับ billing และนำชื่อบริษัทไปดูรายได้เค้า)
17.ลูกค้ารายใดมีแนวโน้มซื้อแพ็กเกจรายปีแทนรายเดือน
(จ่ายรายเดือนมา 3 เดือนแล้ว และมีรายได้ดี)
18.ลูก
ค้ากลุ่มใดมี Margin สูงแต่เราไม่ได้โฟกัส
(ต้องไปเชื่อมกับ billing และนำชื่อบริษัทไปดูรายได้เค้า)19.ลูกค้ารายใดมีธุรกิจเติบโตเร็ว (ดูจาก Traffic / การเพิ่มโดเมน)
(ลูกค้ามีการสั่งซื้อมากกว่า 1 โดเมนใน 1 เดือน)
20.ใครมีพฤติกรรมคล้ายลูกค้า Enterprise
(ต้องไปเชื่อมกับ billing และนำชื่อบริษัทไปเชื่อม dbd /credentเกิน 100 ล้าน)
21.ลูกค้ากลุ่มใดมีโอกาสขาย Reseller Hosting หรือ vps
(ลูกค้ามีการสั่งซื้อโดเมนหรือโฮสต์มากกว่า 5 ใน 1 เดือน)
22.ลูกค้ากลุ่มใดเคยยกเลิกแล้วกลับมา
23.ลูกค้ากลุ่มใดมักอัปเกรดภายใน 1 หรือ 3 เดือนแรก
24.ลูกค้ารายใดเคยอัปเกรดมาแล้ว 1 ครั้ง (มีโอกาสอัปเกรดซ้ำ)?
25.ลูกค้ากลุ่มใดควรเสนอ Managed Service
26.ลูกค้ารายใดกำลังจะครบ 1 เดือนแรก (ช่วงที่มักอัปเกรด)?
27.ลูกค้ารายใดกำลังจะต่ออายุ 
28.ลูกค้ารายใดกำลังจะหมดสัญญาใน 30–60 วัน
29.ลูกค้ารายใดมีรายได้ธุรกิจสูง (ดูจากประเภทธุรกิจ) แต่ใช้แพ็กเกจพื้นฐาน
30.ลูกค้ากลุ่มใดอยู่ในอุตสาหกรรมที่ต้องการ Security สูง
31.ใครซื้ออะไร สั่งซื้ออย่างเดียวไม่จ่ายเงิน
32.ใครสั่งซื้อถึงปีไหน 2024 เผื่อปี 2025 ไปตามเขากลับมา
33.ใครซื้อปริมาณเยอะ หรือสินค้าเดียวกันหลายๆ ตัว
34.บริษัทหรือคนไหน รวยสุด อ้างอิงจาก billing



The AI will automatically generate SQL queries.
